# Troubleshooting

## Tracking software does not start

Check:

- Ubuntu is correctly booted
- Cameras are connected
- Tracking project opens in PyCharm

---

## Cameras are not detected

Check:

- USB connections
- Camera power
- Ximea software

---

## DeepLabCut model cannot be loaded

Check:

- Neural network directory
- Model configuration
- Tensorflow installation

---

## Unreal Engine cannot connect to Tracking

Check:

- Ethernet connection
- Firewall settings
- Tracking software running

---

## Projectors remain black

Check:

- nDisplay Listener running
- nDisplay Launcher configuration
- Projectors powered on

---

## Animal is not detected

Check:

- Reference images
- Lighting conditions
- Exclusion masks
- Detection thresholds

---

## Calibration seems incorrect

Re-run:

1. Space calibration
2. Reference image acquisition

Verify that no camera has moved.
