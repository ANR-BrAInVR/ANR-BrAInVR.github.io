# Recording Scheduling Tests

This page evaluates how accurately GoPro Labs recording instructions control the effective recording schedule of the MISSION 1 cameras.

Two scheduling strategies were tested:

1. **relative scheduling**, where the next recording starts after a specified waiting period;
2. **absolute scheduling**, where every start and stop event is explicitly associated with a clock time.

Scheduling accuracy should not be confused with camera synchronization. Two cameras can execute the same schedule while still starting their recordings at slightly different times.

## Relative scheduling test

A multi-camera test was performed in open air using a **relative GoPro Labs recording loop**.

The next recording was scheduled after a relative waiting period rather than from a new absolute clock time.

Each camera therefore successively:

1. records the video;
2. stops acquisition;
3. finalizes and writes the video;
4. waits for the requested duration;
5. starts the next recording.

Processing and file-finalization time can therefore affect the actual beginning of the next sequence.


### Observed file timestamps

This behaviour can be observed directly in the filenames generated by CAM02:

| Sequence | CAM02 video timestamp |
|---|---:|
| 1 | 13:00:03 |
| 2 | 13:30:09 |
| 3 | 14:01:16 |
| 4 | 14:30:23 |
| 5 | 15:00:30 |

The recordings do **not** start exactly on the theoretical 30-minute grid.

!!! important "Relative scheduling"
    A relative recording loop should not be considered an accurate common timebase.

    Processing associated with the previous sequence can affect the effective timing of the following sequence.

## Relative vs absolute scheduling

The two strategies solve different problems.

| Strategy | Advantage | Limitation |
|---|---|---|
| Relative loop | Compact instruction and simple repeated cycle | Processing delays can propagate to subsequent sequences |
| Absolute schedule | Every recording window is independently defined | Does not guarantee simultaneous effective start across cameras |

!!! success "Current strategy"
    Absolute scheduling is preferred for future NemoReefRecord experiments because each recording window is independently anchored to a predefined clock time.

    Acoustic synchronization is still required to measure the actual inter-camera offset.
